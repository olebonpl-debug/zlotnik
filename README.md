# Злотник

Личная книга расходов в злотых — одностраничное приложение (PWA). Данные хранятся в браузере; из приложения можно выгрузить и восстановить резервную копию.

Сайт публикуется через GitHub Pages из корня ветки `main`: [https://olebonpl-debug.github.io/zlotnik/](https://olebonpl-debug.github.io/zlotnik/).
